################ DATA DESCRIPTION (PlanSage) ################
**Foundational Prefix:**
@prefix base: <https://base_ontology.com#> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix skos: <http://www.w3.org/2004/02/skos/core#> .
@prefix xsd: <http://www.w3.org/2001/XMLSchema#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .

**Data Description:**
1. cell_name: categorical - name of the cell line or biosample - string
2. chrom: text - chromosome identifier - string
3. gene_symbol: text - symbol of the gene - string
4. se_id: text - identifier for the super-enhancer - string
5. rank: Numerical - rank of the super-enhancer - integer
6. start: Numerical - start position of the genomic coordinate - integer
7. stop: Numerical - stop position of the genomic coordinate - integer

**classes:**
1. CellLine
2. Chromosome
3. Gene
4. SuperEnhancer
5. GenomicCoordinate

**subclasses:**
1. CellLine: subclass of -> base:Entity
2. Chromosome: subclass of -> base:Entity
3. Gene: subclass of -> base:Entity
4. SuperEnhancer: subclass of -> base:RegulatoryElement
5. GenomicCoordinate: subclass of -> base:Entity

**Object Properties:**
1. hasChromosome: SuperEnhancer - Chromosome
2. targetsGene: SuperEnhancer - Gene
3. locatedIn: SuperEnhancer - GenomicCoordinate
4. expressedIn: SuperEnhancer - CellLine

**Data Type Properties:**
1. cellName: CellLine - xsd:string
2. chromName: Chromosome - xsd:string
3. geneSymbol: Gene - xsd:string
4. seID: SuperEnhancer - xsd:string
5. rankValue: SuperEnhancer - xsd:integer
6. startPosition: GenomicCoordinate - xsd:integer
7. stopPosition: GenomicCoordinate - xsd:integer

<#TriplesMapCellLine> a rr:TriplesMap;
    rml:logicalSource [
        rml:source "dbSUPER.csv";
        rml:referenceFormulation ql:CSV
    ];
    rr:subjectMap [
        rr:template "https://base_ontology.com#CellLine/{cell_name}";
    ];
    rr:predicateObjectMap [
        rr:predicate base:cellName;
        rr:objectMap [
